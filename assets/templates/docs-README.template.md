# {{repository_name}} 文档入口

本文件是文档入口，回答每类事实由哪里裁决。

## 阅读顺序

1. `AGENTS.md`：执行约束。
2. 本文件：文档地图。
3. `docs/design/`：已确认设计、计划和根因记录。
4. `docs/workorders/`：实施与验收记录。
5. `docs/design/全局待办登记册.md`：开放事项。

## 事实源

| 问题 | 首要事实源 | 漂移处理 |
|---|---|---|
| 当前实现行为 | 指定 commit 的代码、测试和可追溯产物 | 修正文档或登记偏差 |
| 开发约束 | `AGENTS.md` 与适用流程文档 | 代码违规不改变约束效力 |
| 目标设计 | `docs/design/方案-*.md` | 通过新设计或工单修订 |
| 根因 | `docs/design/排查-*.md` 或设计对应章节 | 不改写历史证据 |
| 工单结果 | `docs/workorders/WO-*.md` | 更新工单记录，不只更新对话 |
| 开放事项 | `docs/design/全局待办登记册.md` | 只有有证据才可关闭 |
| 已发布行为 | 发布记录和对应不可变产物 | 目标设计不是发布事实 |
| 历史解释 | 历史 design、workorder 和诊断文档 | 只提供背景 |

## 生命周期

```text
draft -> active -> superseded -> historical
```

- `draft`：已提出，不作为裁决依据。
- `active`：当前有效。
- `superseded`：已被替代，必须指向替代对象。
- `historical`：只解释历史，不指导当前实现。

目标设计必须显式说明是目标，不得伪装成当前行为。

## 更新责任

| 变化 | 必须更新 |
|---|---|
| 行为或接口 | 设计与工单记录 |
| 文档类型或事实源 | 本文件 |
| 范围或验收变化 | 当前工单 |
| 开放或关闭事项 | 全局待办登记册 |
| 发布产物 | 发布记录 |

文档检查不能替代测试、安全评审、运行验证或业务验收。
