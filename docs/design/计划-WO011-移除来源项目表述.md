# WO-011 实施计划：移除来源项目表述

## 目标

从当前源码、模板、参考文档、测试和治理记录中移除来源业务项目名称及专属模型、工具、数据集表述，使公开仓库只保留通用仓库治理方法。

## 改动要点

1. 将来源项目名称替换为“来源项目”或通用描述。
2. 将专属模型名替换为“模型 A / 模型 B”。
3. 将专属外部执行工具描述替换为“外部执行 CLI”。
4. 调整测试中的敏感词断言，继续验证通用输出不携带来源项目专属配置。
5. 当前树清理并验收后，创建无历史新根提交并强推远端 `main`，移除公开可达历史中的旧描述。

## 风险与处理
