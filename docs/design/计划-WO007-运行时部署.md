# WO-007 实施计划：运行时部署

## 目标

实现 `repo-governance` 的版本声明、部署脚本和部署参考，并将当前版本以 symlink 安装到 Codex 全局 skills 目录。部署脚本默认拒绝覆盖已有目标。

## 设计要点

1. `VERSION` 是当前源码版本事实源，初始版本 `0.1.0`。
2. `scripts/deploy.py` 支持 `symlink` 和 `copy` 两种模式。
3. 默认安装到 `~/.codex/skills/repo-governance`。
4. 目标路径已存在时 fail-closed，不提供静默覆盖。
5. symlink 使用相对路径指向源码仓库，便于源码更新后即时生效。
6. copy 模式排除 `.git`、缓存和虚拟环境，仅用于不可使用 symlink 的环境。
7. 部署前校验源码存在 `SKILL.md` 和 `VERSION`。

## 文件职责

1. `scripts/deploy.py`：安装前置检查、symlink/copy、结果输出。
2. `references/deployment.md`：版本、安装、验证、更新和回退。
3. `tests/test_deploy.py`：临时目录安装、拒绝覆盖、copy 排除规则。
4. `VERSION`：当前版本。
5. `README.md`：运行时安装与验证命令。

## 验收

```bash
python3 -m unittest discover -s tests -v
python3 scripts/deploy.py --destination ~/.codex/skills/repo-governance
python3 /Users/2mol/.codex/skills/.system/skill-creator/scripts/quick_validate.py /Users/2mol/.codex/skills/repo-governance
python3 /Users/2mol/.codex/skills/.system/skill-creator/scripts/quick_validate.py .
git diff --check
```

## 不做什么

1. 不推送远端。
2. 不修改 Codex 全局配置。
3. 不覆盖任何既有 skill。
4. 不自动创建 Git tag；tag 在合并后按版本记录单独执行。
