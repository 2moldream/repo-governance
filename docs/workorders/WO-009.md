# WO-009 设置显式调用

## 背景

用户确认 `repo-governance` 只用于初始化仓库或治理历史仓库；普通开发任务应遵循目标仓库自身规范，不应自动加载本 Skill。

## 根因

当前 Skill 未配置 `allow_implicit_invocation: false`，自动选择可能在目标仓库已有 AGENTS 规范时引入第二套流程，造成重复或冲突。

```

事实源变化：有；agents/openai.yaml 成为调用策略事实源
待办变化：无
```

## 实施要求

1. `policy.allow_implicit_invocation` 必须为 `false`。
2. 默认 prompt 必须显式包含 `$repo-governance`。
3. Skill description 必须限定为仓库治理初始化或历史仓库治理诊断。
4. 普通开发任务不得调用。
