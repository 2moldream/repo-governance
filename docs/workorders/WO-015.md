# WO-015 同步主工作区保护与冻结证据入仓规则

## 背景

覆盖度例行对比（来源项目 2026-11-06 以来 199 提交）发现两条可通用化的新治理规则：主工作区零操作保护（来源 WO-377，源于两次真实越权事故——共享基线的主工作区被工单执行/合并操作污染，未跟踪文件无 Git 保护）与冻结证据仓内化（来源 WO-376——回归/冻结证据挂在仓库外易失路径，验收随环境漂移）。用户 2026-11-09 确认「同步」。

## 实施要求

1. worktree-protocol.md 新增「共享工作区保护」节：识别条件（多会话共享+承载共享基线/集成分支）、零操作清单（switch/checkout/stash/merge/rebase/reset/restore/clean/commit/push/分支与 worktree 管理/文件增删改移全禁）、未跟踪文件与脏状态只登记报告不清理不隔离、工单与集成的替代执行位置（独立 worktree）、与单人分支豁免的边界。
2. workorder-registry.md 新增发号器 worktree 绑定：从目标 worktree 根运行或显式 -C/等价参数指定目标；被保护的共享工作区直接拒绝发号。
