# WO-005 沉淀 Worktree 与合并治理

## 背景

多分支、多 worktree 长期演进能隔离并行任务，但缺少协议时容易出现同一分支多处检出、脏工作区覆盖、依赖顺序错误和未验收分支合并。

## 根因

总方案只定义了 L3 原则，缺少 worktree 生命周期、registry 登记和合并前 fail-closed 检查。

## 实施要求

1. L3 默认关闭，启用必须用户确认。
2. 每张 WO 独立 worktree 和分支。
3. Registry 必须记录 worktree 与 placeholder。
4. 合并前检查脏状态、范围、验收、依赖和分支差异。
5. 集成分支禁止直接实现提交。
6. 冲突保留现场并停止。
