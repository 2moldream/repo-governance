# WO-003 实现工单共享 Registry

## 背景

统一编号和 placeholder-first 是避免并行撞号、范围冲突和合并混乱的核心机制。WO-001 只定义了 registry 结构，尚未提供可执行实现。

## 根因

当前 registry 由主会话手工维护，缺少锁、原子写入、状态流转和校验；一旦并行会话同时发号，无法从机制上防止撞号或跳号后复用。

## 实施要求

1. Registry 路径基于目标仓库 Git common dir。
2. 所有写入持锁并原子替换。
3. `allocate` 状态为 `reserved` 且不得带 placeholder。
4. `activate` 必须验证 placeholder commit 存在。
5. `active/completed` 必须有 placeholder。
6. `abandoned` 编号保留且不可复用。
7. `validate` fail-closed，发现任何结构或状态问题返回非零。
8. 不引入第三方依赖。
